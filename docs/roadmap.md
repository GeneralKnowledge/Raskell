# Roadmap

## Near term

- [ ] Broader `while` / stateful loop recognition
- [ ] More iterator adapters (`zip`, `chain`, `enumerate`, …)
- [ ] Explicit `String` builders → efficient Haskell equivalents
- [ ] Generics on functions and data types
- [ ] Better `explain` output with rendered Haskell snippets

## Medium term

- [ ] Traits → type classes
- [ ] Error propagation (`?`) → `Either` / `Maybe` do-notation
- [ ] Async subset → `IO` / async libraries
- [ ] Property-based differential testing

## Long term

- [ ] Channels → STM
- [ ] Source maps & comment preservation
- [ ] Incremental compilation & LSP
